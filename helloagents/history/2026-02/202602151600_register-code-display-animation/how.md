# 技术设计: 注册验证码提示延迟与缓慢显示

## 技术方案
### 核心技术
- React 状态管理（`useState`）
- React 副作用与定时器（`setTimeout` + 清理）
- Tailwind CSS 过渡类（或等价现有样式机制）

### 实现要点
- 新增“验证码提示内容状态”与“是否进入可见态状态”。
- 发送验证码成功后：
  - 登录态：不启用延迟动画逻辑。
  - 注册态：先写入提示内容并保持隐藏，2 秒后切换为可见态。
- 切换登录/注册模式、输入手机号变化或再次请求验证码时，重置显示状态并清理旧定时器，避免脏显示。

## 安全与性能
- **安全:** 不涉及鉴权、权限、隐私数据持久化；仅前端临时展示。
- **性能:** 定时器仅在注册发送成功后创建，且在状态变化时清理，避免内存泄漏。

## 测试与部署
- **测试:**
  - 手工验证注册态下“2 秒后显示 + 缓慢淡入”。
  - 校验登录态不出现该提示动画。
  - 校验多次点击、切换模式、切换手机号时不会出现旧定时器残留。
- **部署:** 前端常规构建发布，无额外配置。
