# 知识星球问答小程序 - 后端整体架构方案（WHY）

> 方案包: backend-core  
> 版本: v1.0  
> 日期: 2026-02-01

## 一、背景与问题

- 现有项目仅有前端实现，缺少与之匹配的后端服务与 API。
- 前端已定义清晰的类型与 API 预期（`src/types/api.ts` 等），需要一个稳定的 RESTful 后端作为支撑。
- 后端需求文档与测试用例已经成型，需要一个可落地的整体架构方案来承接实现。

## 二、目标

- 提供一套与前端契约一致的 RESTful API。
- 实现用户认证、白名单与课时控制、问题/回答/评论、点赞收藏、审核与行为埋点等完整后端能力。
- 确保良好的可维护性、可测试性和可演进性，并与当前 Node/React 技术栈保持一致。

## 三、方案总体思路

- 采用 Node.js + Express + TypeScript + Prisma + PostgreSQL + Redis 架构。
- 通过分层设计（Controller/Service/Repository）隔离 HTTP、业务和数据访问逻辑。
- 借助 Zod 做运行时参数校验，统一响应与错误码规范，配合 Jest 实现高覆盖率测试。
- 使用 CI 流水线自动执行测试与静态检查，确保质量。
