# 安全风险与加固建议（兼容版）

## 风险 1：数据库和 Redis 暴露到公网
- 风险等级：高
- 现状：本模板已默认绑定 `127.0.0.1`，降低公网暴露风险
- 建议：云端继续配合安全组/防火墙限制 5432、6379

## 风险 2：环境变量误配导致“跨环境串线”
- 风险等级：高
- 典型问题：把本地 `FRONTEND_DIST_PATH` 带到云端，或把云端域名带到本地
- 建议：
- 本地和云端各自保存一份 `.env.deploy`（例如 `.env.local`、`.env.prod`）
- 上线前做一次变量核对清单

## 风险 3：弱密码和弱密钥
- 风险等级：高
- 建议：
- `POSTGRES_PASSWORD` 使用强随机密码
- `JWT_SECRET` 至少 32 位随机字符串

## 风险 4：敏感文件提交到 Git
- 风险等级：高
- 建议：
- 只提交 `06-.env.example`
- 真实 `.env.deploy` 加入 `.gitignore`

## 风险 5：前端 dist 目录不是最新
- 风险等级：中
- 现象：页面访问到旧版本
- 建议：每次发布前固定执行 `npm run build`，并检查 `dist` 时间戳

## 风险 6：无备份
- 风险等级：中
- 建议：
- PostgreSQL 定时 `pg_dump`
- 备份至少保留近 7 天
