## 二、用户认证接口测试

### 2.1 发送验证码

#### 测试用例 AUTH-API-001: 正常发送验证码

**请求参数:**

```json
{
  "phone": "13800138000",
  "type": "login"
}
```

**预期响应 (200):**

```json
{
  "code": 200,
  "message": "验证码已发送",
  "data": {
    "phone": "13800138000",
    "expireIn": 300,
    "cooldown": 60
  }
}
```

**验证点:**

- ✓ HTTP状态码为200
- ✓ 数据库中创建验证码记录
- ✓ 验证码有效期为5分钟
- ✓ 短信发送成功（检查日志）
- ✓ 返回冷却时间60秒

#### 测试用例 AUTH-API-002: 手机号格式错误

**请求参数:**

```json
{
  "phone": "138001380",
  "type": "login"
}
```

**预期响应 (400):**

```json
{
  "code": 400,
  "message": "手机号格式错误",
  "error": "INVALID_PHONE_FORMAT"
}
```

**验证点:**

- ✓ HTTP状态码为400
- ✓ 不发送短信
- ✓ 不创建验证码记录

#### 测试用例 AUTH-API-003: 验证码发送频率限制

**前置条件:** 60秒内已发送验证码

**请求参数:**

```json
{
  "phone": "13800138000",
  "type": "login"
}
```

**预期响应 (429):**

```json
{
  "code": 429,
  "message": "验证码发送过于频繁，请稍后再试",
  "error": "TOO_MANY_REQUESTS",
  "data": {
    "retryAfter": 45
  }
}
```

**验证点:**

- ✓ HTTP状态码为429
- ✓ 返回剩余冷却时间
- ✓ 不发送新的短信
