# 学生端验收清单

> 说明：本清单按「学生 / 家长 / 教师与管理员」三类核心角色列出模块级验收要点，用于上线前的端到端业务验收。具体接口与测试用例以 `codex-develop-doc`、`helloagents/wiki` 以及自动化测试为准。

---

## 一、学生端验收清单

### 1. 认证与身份识别

- [ ] 短信验证码 / 密码登录流程可用（含发送验证码、错误提示、重试节流）。
- [ ] 首次登录 / 注册后，个人中心显示为「学生」角色，信息与后端一致。
- [ ] Token 过期后的重新登录流程正确（401 提示、跳转登录页、刷新后仍保持状态一致）。

### 2. 白名单与课时有效期

- [ ] 不在白名单或课时已过期的学生无法进入「提问」页面，并有明确提示文案。
- [ ] 课时有效的学生可以正常看到提问入口（首页悬浮按钮 / 导航入口）。
- [ ] 课时状态在个人中心或相关页面展示正确（剩余天数、将要过期提示与后端一致）。

### 3. 提问与问题列表

- [ ] 学生可以创建问题（文字 + 图片 + 音频），上传失败有清晰错误提示。
- [ ] 提问后问题出现在「我的提问」列表中，状态（待审核 / 已通过 / 已驳回）正确。
- [ ] 首页问题列表仅展示已通过审核的公开问题，分页与加载更多行为正确。
- [ ] 提问页面中的「解题方法 / 办法」下拉框内容来自后台配置的题目维度（`key=method`），选项名称与后台一致。
- [ ] 当后台关闭解题方法维度或禁用所有选项时，提问页面不展示该下拉框，但学生仍可正常创建问题。
- [ ] 学生选择「暂不确定」选项提问时，请求 payload 中包含 `unknown` 标签，问题详情页中可以看到对应标记。

### 4. 问题详情与回答 / 评论

- [ ] 从首页 / 我的提问进入问题详情页，题干、图片、音频、标签等展示完整。
- [ ] 老师回答后，学生在问题详情中可以看到回复内容、音频播放、好问题标记等信息。
- [ ] 当一个回答包含多段音频时，学生可以在问题详情中看到所有音频段，逐条播放且顺序正确。
- [ ] 学生对自己的问题可以进行评论，评论提交后在刷新页面后仍然存在（真实落库）。
- [ ] 已被驳回或封禁的问题有明确状态展示和提示文案。

### 5. 点赞 / 收藏与我的列表

- [ ] 学生在问题详情和列表页可以进行点赞 / 取消点赞、收藏 / 取消收藏操作。
- [ ] 点赞 / 收藏动作的计数与状态在前端及时更新，并与后端接口保持一致。
- [ ] 「我的点赞」「我的收藏」列表可以正常打开并显示真实数据（非固定 mock）。
- [ ] 点赞 / 收藏后的行为日志正确上报（可通过诊断工具或日志验证）。

### 6. 通知与消息

- [ ] 当问题审核结果变更（`audit_result`）时，学生可以收到通知列表中的消息，点击后跳转到对应的问题详情页。
- [ ] 当老师有新回答（`new_answer`）时，学生可以收到「有新回答」通知，点击后可直接跳转到该回答所在的问题详情，并基于 `answerId` 精准定位到该回答。
- [ ] 未读数、小红点等提醒行为正确，进入详情后未读数相应减少。
- [ ] 通知点开后的跳转目标与通知类型匹配，不会跳错问题或页面。
