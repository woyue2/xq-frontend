## 🚀 环境准备

### 1. 初始化测试数据

```bash
cd backend
npx tsx script/seed-full-acceptance.ts
```

**预期输出**：

- ✅ 深度验收账号清单打印
- ✅ 深度验收环境初始化成功

### 2. 启动后端服务

```bash
# 终端1：启动后端
cd backend
npm run dev

# 终端2：启动前端
npm run dev
```

**验证点**：

- ✅ 后端运行在 http://localhost:3000
- ✅ 前端运行在 http://localhost:5173
- ✅ 数据库连接正常（无报错）

### 3. 多窗口浏览器设置

为支持多角色并行测试，建议准备以下窗口：

- **窗口A（老师）**：Chrome 普通窗口 → http://localhost:5173/login
