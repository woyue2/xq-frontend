# 教师端验收清单

> 说明：本清单按「学生 / 家长 / 教师与管理员」三类核心角色列出模块级验收要点，用于上线前的端到端业务验收。具体接口与测试用例以 `codex-develop-doc`、`helloagents/wiki` 以及自动化测试为准。

---

## 二、教师与管理员端验收清单

> 教师与管理员共用一套后台入口，其中管理员具备额外的系统管理权限。以下验收点按模块拆分，需要结合账号角色分别验证。

### 1. 认证与角色权限

- [ ] 老师账号登录后，个人中心显示为「老师」角色，并展示审核 / 管理入口。
- [ ] 管理员账号登录后，可以看到全部后台管理模块（审核队列、白名单、课时管理等）。
- [ ] 未登录或权限不足的账号访问后台链接时会被拦截并重定向到登录页或首页。

### 2. 问题审核与内容管理

- [ ] 老师在审核队列中可以看到待审核问题 / 回答 / 评论列表，分页与筛选（按状态、时间）正常。
- [ ] 审核操作（通过 / 驳回 / 封禁）会正确更新问题状态，并触发对应通知。
- [ ] 老师可以对问题进行「标记好问题」「置顶」等操作，前端展示与排序符合设计。
- [ ] 被封禁 / 隐藏的问题不会对学生 / 家长端造成越权展示。

### 3. 回答与我的回答列表

- [ ] 老师可以在问题详情页进入回答页面，提交文字 / 音频回答，并在刷新后仍然存在。
- [ ] 同一条回答可以包含多段音频，老师可以录制多段、删除某一段或重新录制，提交后所有音频段都被保存。
- [ ] 每段音频录制时长限制在 60 秒内，超过限制时前端有明显提示或自动终止录制，后端拒绝异常时长的数据。
- [ ] 回答提交后出现在「我的回答」列表页面，支持按时间 / 状态筛选（如有设计）。
- [ ] 从「我的回答」列表进入问题详情，链接与页面状态正确，包含多段音频的回答在学生端 / 家长端能完整查看和播放。
- [ ] 学生和家长进入问题详情页时看不到回答入口和录音按钮，只有老师角色可以录音回答。

### 4. 白名单管理与课时批量更新

- [ ] 在白名单管理页面可以看到当前白名单列表，包括手机号、角色、状态、课时有效期等字段。
- [ ] 支持新增白名单用户，重复手机号 / 非法数据会有前端与后端双重校验提示。
- [ ] 支持编辑 / 删除白名单记录，操作后前端列表与后端数据保持一致。
- [ ] 课时批量更新接口（`/api/admin/class-hours/batch-update`）可通过前端操作触发，更新结果在白名单列表和学生/家长端体验中可见。
- [ ] 前端对白名单状态和课时有效期的展示与后端 `isMemberActive` / `validUntil` 字段计算结果一致，尤其是接近到期和跨零点边界等临界时间点。
- [ ] 白名单与课时接口的权限校验正确，仅老师 / 管理员可访问。

### 5. 通知、行为埋点与上传

- [ ] 老师可以在通知模块查看与审核、回答相关的提醒（包括 `audit_result` 与 `new_answer`），未读数与阅读状态更新正确。
- [ ] 学生 / 家长收到的 `new_answer` 通知文案与后台配置一致，通知中包含 `answerId` 等必要信息，点击后可精准跳转到对应回答所在的问题详情。
- [ ] 审核通过 / 驳回操作会触发 `audit_result` 类型通知，学生 / 家长端看到的状态与老师侧操作保持一致。
- [ ] 点击「好问题」「收藏」「白名单操作」等关键行为时，行为日志会按约定结构写入（可通过诊断工具或日志验证）。
- [ ] 上传签名 / 音频等接口在老师端可用，音频上传支持多段 URL 数组，前端对文件类型、数量、单段时长等做基础校验，后端拒绝非法或超限文件。
- [ ] 音频文件实际保存在服务器文件系统或对象存储中，数据库只保存音频 URL / 元数据，不直接存储大体积二进制内容。

### 6. 系统稳定性与联调配置

- [ ] 在联调 / 测试 / 生产环境中确认 `VITE_USE_MOCK=false`，前端所有关键操作（登录、提问、审核、白名单等）均走真实接口。
- [ ] 在生产环境下，认证与白名单相关接口不再使用"内存降级"策略，数据库异常会通过 5xx 错误显式暴露。
- [ ] E2E 测试（`npm run test:e2e`）覆盖学生 / 家长 / 老师三类主链路，特别包括题目维度配置、老师多段音频回答、`new_answer` 通知跳转等关键链路，作为回归验收依据之一。

### 7. 题目维度与解题方法配置（解题方法 / 办法）

- [ ] 管理员可以在后台看到「题目维度配置（解题方法 / 办法）」模块，列表中至少包含 `key=method` 的维度记录。
- [ ] 管理员可以修改解题方法维度的名称、启用状态，并新增 / 编辑 / 禁用具体方法选项（如「公式法」「图像法」等）。
- [ ] 管理员可以为某个选项标记为「暂不确定」（`unknown`），前端提问页对应显示为「暂不确定」，并在提交时写入 `unknown` 标签。
- [ ] 当某个方法选项被禁用后，前端提问页下拉框中不再展示该选项，已有历史问题中仍保留原有显示。
- [ ] 当解题方法维度整体被关闭时，后台配置状态与前端提问页的展示一致（不再显示下拉框），且不会影响已有问题的查看与回答。
