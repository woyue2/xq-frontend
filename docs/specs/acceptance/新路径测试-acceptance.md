## 🚀 环境准备

### 1. 数据库初始化（手动写入管理员）

> **重要**: 本测试场景从零开始，需要手动在数据库中写入初始管理员账号。

#### 1.1 连接数据库

```bash
# 使用 psql 或数据库客户端连接
psql -h localhost -U kpqa -d kpqa_db
```

#### 1.2 写入管理员白名单

```sql
-- 插入管理员白名单
INSERT INTO "Whitelist" (
  "id",
  "phone",
  "name",
  "role",
  "validUntil",
  "isActive",
  "createdAt",
  "updatedAt"
) VALUES (
  gen_random_uuid(),
  '11111111111',
  '系统管理员',
  'TEACHER',
  '2099-12-31 23:59:59',
  true,
  NOW(),
  NOW()
);
```

```sql
-- 插入管理员用户（需要先生成User记录）
INSERT INTO "User" (

) VALUES (
  gen_random_uuid(),

  '管理员',

  '$2b$10$xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx', -- bcrypt hash of 'admin123'
  'TEACHER',

  NOW()

```

**说明**: 密码 `admin123` 的 bcrypt hash 需要使用以下命令生成：

```bash
# 生成 bcrypt hash
htpasswd -nbB admin123
# 或使用 Node.js
node -e "console.log(require('bcryptjs').hashSync('admin123', 10))"
```
