# 环境配置与云端部署指南

## 配置文件位置

### 根目录配置文件

| 文件                 | 用途                          |
| -------------------- | ----------------------------- |
| `.env`               | 开发环境主配置                |
| `.env.production`    | 生产环境配置                  |
| `.env.test`          | 测试环境配置                  |
| `docker-compose.yml` | PostgreSQL + Redis 服务配置   |
| `vite.config.ts`     | Vite 构建配置、代理、测试环境 |

### 前端配置（src/config/）

| 文件               | 用途                  |
| ------------------ | --------------------- |
| `ui-config.ts`     | UI 颜色主题、角色样式 |
| `feature-flags.ts` | 功能开关              |
| `app-constants.ts` | 常量定义              |

### 后端配置（backend/）

| 文件                     | 用途                 |
| ------------------------ | -------------------- |
| `.env`                   | 后端运行时配置       |
| `.env.example`           | 后端配置模板         |
| `src/config/env.ts`      | 环境变量 schema 验证 |
| `src/config/ai-audit.ts` | AI 审核服务配置      |

## 云端部署必改项

### 后端配置（优先级最高）

- `JWT_SECRET` → 强随机字符串（32位+）
- `DATABASE_URL` → 云数据库地址
- `REDIS_URL` → 云 Redis 地址
- `CORS_ORIGIN` → 前端实际域名
- `BACKEND_URL` → 云端后端地址

### 前端配置

- `VITE_API_BASE` → 云端 API 地址

## 安全检查清单

- [ ] JWT_SECRET 使用随机字符串
- [ ] 数据库密码为强密码
- [ ] CORS 禁止使用通配符 `*`
- [ ] 敏感 Token 不提交到代码仓库
