## 2026-02-13

### 变动
阅读可访问性策略从“三档微调”升级为“六档大字号优先”，并要求字号控制在点击外部区域后自动收起。

### 原因
现有字号提升幅度仍不足，影响阅读舒适度；字号面板持续展开也会干扰浏览连续性。

### 影响
前端阅读体验将以大字号可读性为优先；后续页面验收需覆盖极大字号场景下的版面稳定性。

## 2026-02-14

### 变动
Profile 页面账户安全入口图标从“带底色块”调整为“无底色”，视觉规范与同页功能入口保持一致。

### 原因
带底色图标在该区块形成额外视觉强调，弱化了列表信息层级一致性。

### 影响
个人中心入口样式标准统一到“轻容器图标”方向，后续新增同类入口需遵循同一视觉基线。

## 2026-02-14

### 变动
问题列表互动状态从“前端临时态”调整为“后端回传用户态 + 前端合并态”。

### 原因
刷新和跨页面跳转后，点赞/收藏状态容易回退，导致用户感知不一致。

### 影响
列表接口需要感知当前用户身份；互动状态在列表与详情之间保持一致基线。

## 2026-02-14

### 变动
问题难度流程从“审核时可空缺”升级为“审核通过强约束 + 老师可在通过后二次调整”。

### 原因
难度空值会削弱题目分层能力，且老师在教学反馈后缺少纠偏入口。

### 影响
审核链路与教学链路共享同一难度治理规则，难度标签从一次性填写转为可持续维护。

## 2026-02-14

### 变动
个人中心入口图标语义从“混合图标库 + 不稳定底色策略”收敛为“统一图标体系 + 稳定浅色映射”。

### 原因
入口图标在不同终端出现语义重复和底色失真，影响导航辨识度。

### 影响
个人中心入口视觉规范趋于一致，后续新增入口可沿用同一映射规则降低样式漂移风险。

## 2026-02-14

### 变动
问题详情页互动按钮色彩策略从“与列表分离”调整为“与列表卡片统一色值体系”。

### 原因
同一互动动作在不同页面使用不同色值，会放大状态判断成本并降低一致性感知。

### 影响
用户在列表与详情页之间切换时，互动状态识别路径更稳定，视觉语义更连续。

## 2026-02-14

### 变动
阅读字号策略从“极大化优先”回调为“可读性与版面稳定性平衡”，并同步调整筛选区文字层级。

### 原因
过大字号在部分页面造成信息密度骤降与布局拥挤，影响连续浏览效率。

### 影响
全局阅读体验转向“可读且稳定”的折中方案，后续字号优化需同时评估可读性与排版承载。

## 2026-02-14

### 变动
前端静态资源发布策略从“默认 public 目录 + 资源假定齐备”调整为“显式 static 目录 + 最小可用 PWA 资源集”。

### 原因
资源目录与构建配置不一致导致头像与 PWA 资源存在可用性风险。

### 影响
静态资源交付路径更可控，后续只需补齐高分辨率图标即可平滑升级安装体验。
