# 2026-02-13

### 变动
阅读可访问性策略从“三档微调”升级为“六档大字号优先”，并要求字号控制在点击外部区域后自动收起。

### 原因
现有字号提升幅度仍不足，影响阅读舒适度；字号面板持续展开也会干扰浏览连续性。

### 影响
前端阅读体验将以大字号可读性为优先；后续页面验收需覆盖极大字号场景下的版面稳定性。

## 变动
“好问题”数据来源从“前端在通用问题列表中二次过滤”调整为“后端专用查询入口”。

### 原因
通用列表二次过滤容易出现空态误判，且数据口径受分页窗口影响。

### 影响
好问题页面数据口径与后端规则保持一致，跨页与空态判断更稳定。

# 2026-02-14

### 变动
Profile 页面账户安全入口图标从“带底色块”调整为“无底色”，视觉规范与同页功能入口保持一致。

### 原因
带底色图标在该区块形成额外视觉强调，弱化了列表信息层级一致性。

### 影响
个人中心入口样式标准统一到“轻容器图标”方向，后续新增同类入口需遵循同一视觉基线。

# 2026-02-14

### 变动
问题列表互动状态从“前端临时态”调整为“后端回传用户态 + 前端合并态”。

### 原因
刷新和跨页面跳转后，点赞/收藏状态容易回退，导致用户感知不一致。

### 影响
列表接口需要感知当前用户身份；互动状态在列表与详情之间保持一致基线。

# 2026-02-14

### 变动
问题难度流程从“审核时可空缺”升级为“审核通过强约束 + 老师可在通过后二次调整”。

### 原因
难度空值会削弱题目分层能力，且老师在教学反馈后缺少纠偏入口。

### 影响
审核链路与教学链路共享同一难度治理规则，难度标签从一次性填写转为可持续维护。

# 2026-02-14

### 变动
个人中心入口图标语义从“混合图标库 + 不稳定底色策略”收敛为“统一图标体系 + 稳定浅色映射”。

### 原因
入口图标在不同终端出现语义重复和底色失真，影响导航辨识度。

### 影响
个人中心入口视觉规范趋于一致，后续新增入口可沿用同一映射规则降低样式漂移风险。

# 2026-02-14

### 变动
问题详情页互动按钮色彩策略从“与列表分离”调整为“与列表卡片统一色值体系”。

### 原因
同一互动动作在不同页面使用不同色值，会放大状态判断成本并降低一致性感知。

### 影响
用户在列表与详情页之间切换时，互动状态识别路径更稳定，视觉语义更连续。

# 2026-02-14

### 变动
阅读字号策略从“极大化优先”回调为“可读性与版面稳定性平衡”，并同步调整筛选区文字层级。

### 原因
过大字号在部分页面造成信息密度骤降与布局拥挤，影响连续浏览效率。

### 影响
全局阅读体验转向“可读且稳定”的折中方案，后续字号优化需同时评估可读性与排版承载。

# 2026-02-14

### 变动
前端静态资源发布策略从“默认 public 目录 + 资源假定齐备”调整为“显式 static 目录 + 最小可用 PWA 资源集”。

### 原因
资源目录与构建配置不一致导致头像与 PWA 资源存在可用性风险。

### 影响
静态资源交付路径更可控，后续只需补齐高分辨率图标即可平滑升级安装体验。

### 变动
首页卡片交互从“展示并可切换理解状态”调整为“暂时隐藏理解状态展示入口”。

### 原因
当前阶段优先保证主链路浏览与互动稳定，先收敛非核心状态入口以降低页面干扰。

### 影响
首页信息密度降低、主操作路径更聚焦；若后续恢复理解状态入口，需要重新评估展示位置与触发时机。

## 变动
题目图片上传策略从“可附多图”收敛为“单题单图”。

### 原因
多图输入会放大题目边界不清与排版不稳定问题，不利于后续打印复习场景的稳定输出。

### 影响
提问入口输入标准更统一，后续打印与裁剪链路更容易保持一致性。

## 变动
上传前裁剪从“框选 + 平移”升级为“八方向缩放 + 白色选区高亮”。

### 原因
仅靠单一框选方式难以精确处理边缘内容，选区与非选区对比不足也会增加误裁概率。

### 影响
裁剪操作可控性与可见性提升，题图标准化质量更稳定，减少后续打印前的人工返工。

## 变动
草稿保存策略从“10 秒自动保存”调整为“5 秒自动保存 + 仅内容变化时写入”，并在提问、回答、评论三个入口统一该策略。

### 原因
10 秒间隔在误刷新或意外返回场景下仍有数据丢失窗口；同时固定频率写入会产生重复 I/O。

### 影响
草稿恢复及时性提升；未变更输入场景不再重复写入 localStorage，性能压力更可控；三端草稿行为保持一致，维护成本降低。

## 变动
图片可用性策略从“图床直连单路径”调整为“图床优先 + 上传失败本地兜底 + 读取侧代理兜底”。

### 原因
外部图床在部分网络环境下存在间歇性加载失败，导致“上传成功但页面偶发无法显示”。

### 影响
图片链路由单点依赖转为双通道兜底，提问、回答、评论、审核等页面的图片显示稳定性提升；后续需要持续关注代理带宽与白名单维护。

## 变动 打印复习流程从“题目逐条浏览”调整为“家长选题后批量打印”
### 原因 线下复习需要一次性整合“我的收藏 + 孩子全部题目”，原有浏览路径操作成本高
### 影响 个人中心新增打印入口并形成独立选题链路，后续打印能力可在该链路持续迭代

## 变动 打印输出策略从“仅题目内容直出”调整为“含答题空白区 + 失效题过滤 + 稳定返回兜底”
### 原因 纸质复习需要手写作答空间，且历史失效题会导致重复 404 干扰，影响连续打印
### 影响 打印成品可直接用于线下作答，打印链路在异常题目与导航回退场景下更稳定

## 变动 图片审核链路从“所有图片统一发起 AI 审核”调整为“AI 不可达来源直接转人工审核”
### 原因 本地回落图片常为站内相对路径或私网地址，外部 AI 无法直接访问，继续调用只会放大失败与等待成本
### 影响 不可达图片将快速进入人工审核队列，审核结果更可预期，上传失败本地保留场景下的流程稳定性更高

## 变动 审核问题列表从“仅展示文本”调整为“同步展示题图”
### 原因 老师在审核阶段无法看到题图会降低判断准确性，并增加来回打开详情的成本
### 影响 待审核问题卡片可直接完成图文联审，审核效率与准确性提升

## 变动 顶部品牌与个人页版本展示从“知否/v1.1.0”调整为“题题高/v1.0”
### 原因 当前阶段希望统一对外名称与版本口径，避免页面间品牌与版本信息不一致
### 影响 首页导航与个人中心展示基线统一，后续发布记录需按新口径维护

## 变动
问题维度相关前端链路补充“保留且影响配置数据”的注释说明。

### 原因
当前创建问题页展示文案采用固定选项，容易被误判为“问题维度功能已废弃”，需要明确其仍承担配置数据读写职责。

### 影响
后续维护可区分“展示文案固定”与“后台维度配置仍生效”两层语义，降低误删风险。

## 变动
移除 `seed:question-dimensions` 脚本入口与对应文档命令，避免容器环境继续执行不存在或无必要的维度 seed。

### 原因
当前问题维度功能已通过接口与数据表维持运行，不再依赖单独 seed；保留该命令会在部署/排障时制造误报。

### 影响
部署初始化命令更收敛，运维侧不会再因执行该 seed 命令触发 `MODULE_NOT_FOUND` 类错误。

## 变动 Prisma 本地开发数据库鉴权指引补充（P1000 场景）
### 原因 Docker 数据卷已存在时，修改 `POSTGRES_PASSWORD` 不会回写已创建用户密码，易导致 Prisma/Prisma Studio 报 `P1000 Authentication failed`
### 影响 文档新增“保留数据改密码（ALTER ROLE）/删卷重建”两种处置路径，降低本地联调与排障成本

## 变动 1C1G 部署基线与运维脚本口径同步
### 原因 低配实例部署文档、Caddy/compose 配置与运维排障口径需要与当前实现保持一致，避免按旧步骤上线失败
### 影响 部署执行步骤更可复现；值班排障与回滚路径更统一（同时避免提交生产密钥文件）

## 变动 后端接口联调实现与测试基线对齐
### 原因 前后端联调阶段存在接口行为与测试覆盖缺口，影响回归稳定性与排障效率
### 影响 后端服务、配置与测试用例同步更新后，本地与 CI 的联调验证更稳定，接口行为更可追溯

## 变动 E2E 联调用例与烟测脚本更新
### 原因 端到端用例与鉴权初始化需覆盖最新主链路，避免回归时出现误报/漏报
### 影响 关键流程可通过 E2E 与 smoke 脚本更稳定复现，联调验证成本下降
