## 发现的问题

### ❌ 13. BackendQuestionListItem 缺少 images 字段

**问题：** 前端 `BackendQuestionListItem` 类型没有定义 `images` 字段，但后端列表接口返回了该字段

**后端代码：**
```typescript
// backend/src/services/question.service.ts
return {
    list: list.map((q) => ({
        id: q.id,
        title: q.title,
        content: q.content,
        images: q.images ?? [],  // ✅ 返回 images 数组
        tags: q.tags,
        difficulty: q.difficulty,
        authorId: q.authorId,
        ...
    })),
    ...
};
```

**前端类型：**
```typescript
// src/services/api.ts
type BackendQuestionListItem = {
    id: string;
    title: string;
    content?: string | null;
    tags?: string[] | null;
    difficulty?: string | null;
    authorId: string;
    authorName: string;
    authorAvatar?: string | null;
    isGoodQuestion: boolean;
    isPinned: boolean;
    likes?: number | null;
    favorites?: number | null;
    comments?: number | null;
    answers?: number | null;
    status: string;
    createdAt: string;
    subject?: string | null;
    understoodCount?: number | null;
    notUnderstoodCount?: number | null;
    understandingStatus?: 'understood' | 'not_understood' | null;
    // ❌ 缺少 images
};
```

**影响：**
- 问题列表无法展示图片预览
- 限制了问题列表的多媒体展示能力

### ❌ 18. Question 类型缺少 aiAudit 字段

**问题：** 前端 `Question` 接口没有定义 `aiAudit` 字段，但后端创建问题返回了该字段

**后端代码：**
```typescript
// backend/src/services/question.service.ts
return {
    id: created.id,
    title: created.title,
    content: created.content,
    images: created.images ?? [],
    tags: created.tags,
    difficulty: created.difficulty,
    authorId: created.authorId,
    authorName: created.authorName,
    status: created.status,
    aiResult: created.aiResult,
    createdAt: created.createdAt,
    // 返回审核结果供前端显示
    aiAudit: {
        safe: auditResult.safe,
        reason: auditResult.reason,
        qualitySuggestion: auditResult.quality?.suggestion
    }
};
```

**前端类型：**
```typescript
// src/types/index.ts
export interface Question {
    id: string;
    title: string;
    content?: string;
    images: string[];
    tags?: string[];
    difficulty?: DifficultyLevel;
    status: AuditStatus;
    isPinned: boolean;
    isGoodQuestion: boolean;
    score?: number;
    aiResult?: string;
    understoodCount?: number;
    notUnderstoodCount?: number;
    createdAt: string;
    // ❌ 缺少 aiAudit
}
```

**影响：**
- 问题创建后，前端无法直接获取审核结果
- 用户提交问题后无法立即知道内容是否通过审核
- 无法展示具体的审核建议（如题目清晰度建议）
