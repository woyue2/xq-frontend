## 发现的问题

### ⚠️ 61. 分页参数名不一致

**问题：** 前端使用 `limit`，后端使用 `pageSize`

**前端：**
```typescript
// src/pages/AdminManagementPage.tsx
const res = await adminService.getWhitelist({
    page: 1,
    limit: 50  // ⚠️ 后端不识别
});
```

**后端：**
```typescript
// backend/src/services/whitelist.service.ts
async list(params: {
    pageSize?: number;  // ⚠️ 前端传的是 limit
    // ...
})
```

**影响：** 分页大小参数不生效，默认使用后端默认值 20

**修复建议：**
```typescript
// 前端统一使用 pageSize
export interface WhitelistParams {
    page?: number;
    pageSize?: number;  // 改为 pageSize
    search?: string;
    role?: string;
    status?: string;
}
```

---

### ⚠️ 62. 前端缺少 searchField 参数

**问题：** 后端支持按 `name` 或 `phone` 字段搜索，前端未暴露此参数

**后端支持：**
```typescript
async list(params: {
    // ...
    searchField?: 'name' | 'phone';  // ✅ 支持
})
```

**前端现状：**
```typescript
export interface WhitelistParams {
    page?: number;
    limit?: number;
    search?: string;  // ⚠️ 只能模糊搜索
    role?: string;
    status?: string;
}
```

**修复建议：**
```typescript
export interface WhitelistParams {
    page?: number;
    pageSize?: number;
    search?: string;
    searchField?: 'name' | 'phone';  // 新增
    role?: string;
    status?: string;
}
```

**问题：** 前端页面使用 `expiresAt`，后端使用 `validUntil`

**前端 WhitelistUserItem：**

**修复建议：**
统一使用 `validUntil`，或在类型定义中说明对应关系

**问题：** 科目（Subject）和解题方法（Method）共用 question-dimension 表

**数据库结构：**
```prisma
// questionDimension 表
key: 'subject_math'      // 科目
key: 'subject_chinese'   // 科目
key: 'method'            // 解题方法（不是科目）
```

**影响：**
- `/config/question-dimensions` 返回所有维度（包括非科目）
- `/config/subjects` 需要过滤 `subject_` 前缀
- 数据模型设计不够清晰

**修复建议：**
- 方案 1：科目使用独立的表或配置
- 方案 2：明确约定 `subject_` 前缀为科目标识
- 方案 3：在维度表中添加 `type` 字段区分

```typescript
// backend/src/routes/config.routes.ts

configRouter.get(
  '/subjects',
  async (req: Request, res: Response, next: NextFunction) => {
    try {
      const dimensions = await questionDimensionService.getPublicDimensions();

      const subjects = dimensions
        .filter((dim) => dim.key.startsWith('subject_'))
        .map((dim) => ({
          key: dim.key,
          name: dim.name,
          order: dim.order ?? 0,
          topics: dim.options.map((opt) => ({
            value: opt.value,
            label: opt.label,
            order: opt.order
          }))
        }));

      return res.json({
        code: 200,
        message: 'success',
        data: { subjects },
        timestamp: Date.now()
      });
    } catch (err) {
      next(err);
    }
  }
);
```

```typescript
private transformTaxonomyToDto(taxonomy: Record<string, SubjectConfig>): SubjectDto[] {
    return Object.entries(taxonomy).map(([value, config], subjectIndex) => ({
        key: `subject_${value}`,
        name: config.label,
        order: subjectIndex,
        topics: config.topics.map((topic, topicIndex) => ({

            order: topicIndex * 10,
```
