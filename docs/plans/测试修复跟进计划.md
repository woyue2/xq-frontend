## 二、详细问题分析

### 🔴 类别 A：数据库迁移问题（8个失败）

**影响测试**：
1. `notification.api.spec.ts` - 5个测试失败
2. `notification-new-answer-flow.api.spec.ts` - 1个测试失败
3. `notification-read.api.spec.ts` - 2个测试失败
4. `contract-route-diff.api.spec.ts` - 1个测试失败（依赖 notification）
5. `flow-question-audit-notification.api.spec.ts` - 2个测试失败

**错误信息**：
```
The column `Notification.readAt` does not exist in the current database.
```

**原因分析**：
- Prisma Schema (`backend/prisma/schema.prisma:214`) 已定义 `readAt DateTime?` 字段
- 数据库未执行包含此字段的迁移
- `prisma migrate deploy` 显示"没有待应用的迁移"，说明迁移文件存在但可能未正确执行或数据库版本不一致

**关联性判断**：❌ **与分页格式修改无关**  
这是独立的功能开发遗留问题（新增 `readAt` 字段支持）。

**子任务**：
1. 检查当前数据库迁移状态
   ```bash
   cd backend
   npx prisma migrate status
   ```

   ```bash
   npx prisma migrate deploy
   ```
3. 如果迁移已应用但列仍缺失，可能需要：
