前端气泡动画多方案 Playground

每个方案都包含：气泡生成 ➝ 上升运动 ➝ 摆动 ➝ 透明度渐变 ➝ 边界检测与自动销毁，并暴露可调参数。

方案一：纯 CSS3 关键帧
CSS only

使用多组气泡元素 + keyframes 实现基础上升与轻微摆动，适合作为简单背景特效。

可调参数（通过修改 style 或 CSS 变量）： - 气泡数量：增加 / 删除 <span class="css-bubble"> 元素。 - 尺寸范围：--size（px）。 - 上升时长：--duration（秒） → 等价于速度。 - 生成频率：通过 --delay 和整体数量组合控制。 - 摆动幅度：在 @keyframes cssBubbleRise 中调整 translate3d 的 X 偏移。
方案二：DOM + JavaScript
DOM + rAF

通过 JS 动态创建 / 销毁气泡元素，支持随机大小、速度、摆动幅度等参数，便于与交互联动。

可调参数（见脚本中的 domConfig）： - maxBubbles：屏幕上最多同时存在的气泡数量。 - spawnInterval：生成间隔（毫秒）。 - size.min / size.max：尺寸区间（px）。 - speed.min / speed.max：上升速度区间（px/s）。 - swayAmplitude：左右摆动幅度（px）。 - swaySpeed：左右摆动速度（弧度 / s）。
方案三：Canvas 高性能绘制
Canvas 2D

适合大量气泡和复杂混合效果，通过单个画布集中绘制，减少 DOM 数量，适合 1 核 1G 服务器前端轻量展示。

关键参数（见脚本中的 canvasConfig）： - maxBubbles：最大气泡数。 - spawnPerSecond：每秒生成数量。 - radiusRange：半径范围。 - speedRange：上升速度。 - swayAmplitudeRange / swaySpeedRange：摆动幅度与速度。 性能优化要点：使用 requestAnimationFrame、transform / translate3d、控制最大粒子数。
方案四：SVG 矢量气泡
SVG + JS

使用 SVG circle 元素实现矢量气泡，路径与透明度由 JS 控制，放大不失真，适合与图标 / 插画融合。

可调参数（见脚本中的 svgConfig）： - maxBubbles：最大 SVG 气泡数量。 - spawnInterval：生成间隔（毫秒）。 - radiusRange：半径范围（viewBox 坐标）。 - speedRange：上升速度（viewBox 单位 / s）。 - swayAmplitudeRange：左右摆动幅度。 优点：矢量可缩放、易与其他 SVG 元素组合；缺点：大量节点时要注意 DOM 性能。
